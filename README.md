# Shock Analyzer

Shock Analyzer is a Python-based desktop application for processing and keeping a record of 
shock-tube experimental measurements.

## Features

- Sensor distance selection
- Shock-wave velocity calculation
- Shock Mach number calculation
- N₂ and Ar driven-gas selection
- Automatic sound-speed calculation
- Reflected-shock pressure calculation
- Reflected-shock temperature calculation
- Experimental parameter recording
- CSV data export

## Requirements

- Python 3
- pandas
- tkinter

## Running the application

```bash
python ShockAnalyzer.py
